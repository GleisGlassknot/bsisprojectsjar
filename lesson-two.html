In Mathematics, Sets are defined as a collection of distinct elements. The elements of a set share a common characteristic among them.

Examples:

1. The set of all letters in SAMSON MORENO.

E = {A, E, M, N, O, R, S}


TYPES OF SETS

1. Well-Defined Sets: A set that is clear and unambiguous whether any given object belongs to the set or not, leaving no room for subjective interpretation.

[Example]: D = {x: x is the set of all days in a week}

D = {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday}


2. Empty Sets or Null Sets: It has no element present in it. Also denoted in ∅ symbol.

[Example]: A = {} is a null set.


3. Finite Sets: It has a limited number of elements.

[Example]: A = {1,2,3,4}


4. Infinite Sets: It has an infinite number of elements.

[Example]: B = {x: x is the set of all whole numbers}

B = {0, 1, 2, 3, 4, 5...}


5. Equal Sets: Two sets which have the same members.

[Example]: A = {1,2,5} and B={2,5,1}: Set A = Set B


6. Equivalent Sets: Set A is said to be an equivalent of Set B if they have the same number of elements.

The 'cardinality of sets' refers to the no. of elements a set has.

[Example]: A={1,2}, B={3, 4}, then A ~ B


7. Subset: Set A is said to be a subset of B if each element of A is also an element of B.

a. Proper Subsets: Set A is a proper subset of Set B, if and only if all elements of A are in B, but A ≠ B.

[Example]: A={1,2}, B={1,2,3,4}, then A ⊂ B

b. Improper Subsets: Set A is a proper subset of Set B, if and only if all elements of A are also B.

[Example]: A={1,2}, B={3,4}, then A ⊆ B


8. Universal Set: A set which consists of all elements of other sets present in a Venn diagram.

[Example]: A ={1,2}, B={2,3}, The universal set here will be, U = {1, 2,3}


9. Disjoint Sets: Two sets are disjoint if there are no intersections between their elements.

[Example]: A = {1, 2, 3, 4}, B = {A, B, C, D}



FUNDAMENTAL NUMBER SETS

1. Natural Numbers - The set of common counting numbers. Starts on 1.

N = {1, 2, 3, 4, 5...}


2. Whole Numbers - The set of numbers from zero to infinity that does not include any decimals or fractions.

W = {0, 1, 2, 3, 4, 5...}


3. Rational Numbers - The set of all terminating and repeating numbers; any fraction with non-zero denominators is a rational number.

Q = {1/2, 0.33333..., 1/5, 3/4...}


4. Irrational Numbers - The set of all non-terminating and non-repeating numbers; any fraction with non-zero denominators is a rational number.

F = {..., π, 2–√, 0.121221222...}


5. Real Numbers - The set of all terminating and repeating numbers; any fraction with non-zero denominators is a rational number.

R = {..., −3, −1, 0, 15, 1.1, 2–√, 2, 3, π,…}


6. Integers - The set of any whole number (positive, negative, or zero) with no fractional or decimal part.

Z = {..., -3 , -2, -1, 0, 1, 2, 3...}



SET BUILDER NOTATION

Set Builder Notation is a concise way to define sets by specifying a rule or property that its members must satisfy.

[Examples]

1. [Verbal Description] The set of real numbers greater than -1 but less than or equal to 5.

[Rule Method] { x ∈ R | -1 < x ≤ 5}
R = {0, 1, 2, 3, 4, 5}

2. [Verbal Description] The set of counting numbers greater than 5 but less than 10.

[Rule Method] { x ∈ N | 5 < x < 10}
N = {6, 7, 8, 9}

3. [Verbal Description] The set of integers less than 5 but greater than -3

[Rule Method] { x ∈ R | -1 < x ≤ 5}
R = {0, 1, 2, 3, 4, 5}

4. [Verbal Description] The set of all integers less than 0.

[Rule Method] { x ∈ Z | -∞ > x}
Z = {-1, -2, -3, -4, -5, -6...}



SET OPERATIONS

Set operations are ways to combine, compare, or modify sets.

Given: A = {1, 2, 3, 4}, B = {3, 4, 5, 6}

1. Union (A ∪ B) — all elements in either set

A ∪ B = {1, 2, 3, 4, 5, 6}

2. Intersection (A ∩ B) — elements in both sets

A ∩ B = {3, 4}

3. Difference (A − B) — elements in A but not B

A − B = {1, 2}
B − A = {5, 6}

4. Complement (A' or B'): It is the set of all elements in the Universal set that are not elements of A.

Example: U = {1, 2, 3, 4, 5, 6}, then A' = {5, 6} and B' = {1, 2}
